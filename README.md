Campus Navigator is a high-performance digital infrastructure tool designed to streamline navigation for students and faculty at KC Model School & College. Developed by Glitched Technologies, this application provides real-time access to classroom locations, faculty directories, and campus facilities across 8 levels (Basement to 7th Floor).
## 🚀 Core Features

    🔍 Omni-Filter Search: Instant filtering by Class name, Section (e.g., SB-1), Form Teacher, or Room number.

    📂 Dynamic Floor Directory: Detailed layouts for all levels, from KG and Primary to Secondary and College sections.

    📞 Faculty Connect: Integrated directory with one-tap contact options for class representatives and teachers.

    🎨 Glitched UI/UX: A bespoke, high-contrast dark-mode interface optimized for mobile performance and readability.

    📱 Cross-Platform: Built with React and TypeScript, ready for Vercel web deployment and Android APK distribution.

## 🛠️ Technical Stack

    ⚛️ Frontend: React 18 with TypeScript for type-safe development.

    🎨 Styling: Tailwind CSS for a utility-first, responsive "Glitched" aesthetic.

    🧩 Icons: Lucide React for consistent, scalable vector graphics.

    🧠 State: React Context API for handling global campus data and navigation.

    ⚡ Backend: Supabase for data persistence and Vercel for automated CI/CD.

## 📦 Installation & Setup

To run this project locally, ensure you have Node.js installed.
Bash

# 🛠️ Clone the repository
git clone https://github.com/your-username/campus-navigator.git

# 📁 Navigate to the directory
cd campus-navigator

# ⚡ Install dependencies
npm install

# 🚀 Start the development server
npm run dev
